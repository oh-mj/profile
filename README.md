# My personal website

Built with the [Phantom](https://github.com/jamigibbs/phantom) Jekyll theme and hosted on GitHub Pages.

## Where to edit
- `_config.yml`: your name, tagline, social links, nav
- `about.md`: the About page
- `_posts/`: each file is one card on the home page
- `img/posts/`: card images (replace the placeholders)
- `img/favicon.png`: browser tab icon
